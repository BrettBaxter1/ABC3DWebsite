# ABC3D
An OpenGL 3D modeler from scratch.

University of Utah Spring-Fall 2026 CS Undergrad Capstone Project.

+ Duc La

+ Liam Astin

## Summary
3D modeling software is often complex, which can create an overwhelming or unintuitive experience for beginners. Despite this, 3D modeling is becoming a more desirable capability of ordinary people, it can be an incredibly useful skill for many different types of digital art. As such, the goal of our application will be to make 3D modeling more accessible and enjoyable. To achieve this, our 3D modeling software will need to be capable while remaining relatively simple, straightforward, intuitive, and fun. The application will implement a variety of useful modeling operations, including some that we research and others that we come up with ourselves, and present these operations to the user in intuitive ways. It will also need to export geometry to common file formats for rendering or 3D printing. Our software will have a tutorial system to help teach new users the fundamentals. Users will be able to create their own tutorials and export them, and import tutorials made by others. It will be a desktop application for Windows to streamline the design process and allow for higher processing power.
